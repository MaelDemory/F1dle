# F1dle

Wordle-like game based on Formula 1 drivers.

The goal is to find the driver with some information about him such as his nationality, his age, his number of win..

More drivers are planed to be added in the future. Only the current drivers are available for now.

## Technologies

- React
- TypeScript
- TailwindCSS + shadcn
- Fetch for API calls

## Memo

F1dle is using my own REST [API](https://github.com/MaelDemory/F1dle-API)
